# 1.0.56+58

## 새 기능
- 앱을 다시 열면 홈 화면의 일정·실적 정보를 자동으로 최신 상태로 갱신합니다. (관리자가 웹에서 행사 일정을 확정한 내용이 재로그인 없이 반영됩니다)

## 개선
- 주문서 이탈 확인 팝업에서 "임시저장"을 선택하면 저장 후 화면이 정상적으로 닫히도록 수정했습니다.
- 주문서를 임시저장한 뒤 변경한 내용이 없으면 뒤로 가기 시 확인 팝업 없이 바로 나가도록 개선했습니다.
- 공지사항 본문의 여러 줄 빈 줄이 작성한 그대로 표시되도록 수정했습니다.
- 공지 상세의 분류 배지 글자가 잘 보이지 않던 문제를 수정했습니다.
