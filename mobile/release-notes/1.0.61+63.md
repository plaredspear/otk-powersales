# 1.0.61+63

## 새 기능
- 주문서 툴바에 담긴 제품 건수가 항상 표시되고, 100개를 넘으면 강조됩니다.
- 제품 담기 개수 제한(100개)이 풀렸습니다. 100개를 넘겨 담을 수 있고 승인요청만 제한됩니다.
- 승인요청 버튼을 누를 수 없을 때, 그 이유를 안내 문구로 알려주고 해당 입력 항목으로 바로 이동합니다.
- 제품 추가 화면 상단에 이미 담긴 제품 개수가 표시됩니다.

## 개선
- 확정 버튼에 `선택 / 추가 후 총 수` 가 표시되어 담기 결과를 바로 확인할 수 있습니다.
- 승인요청 버튼 문구가 실제 제한 사유와 다르게 나오던 문제를 수정했습니다.
- 납기일 선택 시 주문 가능한 최초일보다 이전 날짜를 고를 수 없도록 했습니다.
- 임시저장 시 거래처를 반드시 입력해야 하던 제한을 없앴고, 제품이 하나도 없으면 임시저장되지 않도록 했습니다.
- 마감이 지난 경우 안내 문구를 '납기일 확인필요' 로 바꿔 무엇을 해야 하는지 알기 쉽게 했습니다.
- 임시저장 안내 문구가 화면을 벗어나 잘리던 문제를 수정했습니다.
