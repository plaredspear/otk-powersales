# 1.0.69+71

## 개선
- 일 매출 등록 화면이 개편되었습니다. 담당 행사가 행사번호 대신 `[행사유형]행사명` 으로 표시되고, 화면 상단에서 날짜와 행사를 항상 확인·변경할 수 있습니다. 대표 제품과 기타 제품의 제품명·제품코드도 함께 표시되며, 입력 누락 안내 문구와 전송 확인 절차를 정비했습니다.
- 재고 조회 시 출고정지 고객 등 조회할 수 없는 사유가 있으면, 시스템 오류 대신 실제 사유가 안내됩니다.
- 클레임 목록에서 유통기한이 미래인 건이 조회되지 않던 문제를 수정했습니다. 목록의 기간 조회와 표시 날짜 기준을 등록일로 맞췄습니다.
