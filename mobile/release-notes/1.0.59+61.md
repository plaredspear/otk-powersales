# 1.0.59+61

## 새 기능
- 주문서 제품검색에서 최근 10일 안에 주문한 제품이 목록 위쪽에 배지와 함께 표시됩니다.
- 주문서 제품검색이 전체 제품을 끊김 없이 이어서 볼 수 있도록 바뀌었습니다.

## 개선
- 주문서 제품검색에서 스크롤을 내려도 다음 목록이 나오지 않던 문제를 수정했습니다.
- 주문서 제품검색 결과의 정렬 순서를 기존 시스템과 동일하게 맞췄습니다.
- 교육 자료에서 카테고리를 바꿔도 이전 카테고리 목록이 남아 있던 문제를 수정했습니다.
- 교육 자료에 동영상·문서 파일을 첨부할 수 없던 문제를 수정했습니다.
- 출근등록 완료 화면에서 불필요한 제품유형 표시를 제거했습니다.
