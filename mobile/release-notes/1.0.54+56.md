# 1.0.54+56

## 새 기능
- 클레임 목록·상세에서 상태 옆 안내 아이콘을 눌러 각 상태의 의미를 확인할 수 있습니다.
  (미확인 / 처리 상태 / 전송실패 구분과 매시간 자동 갱신 안내)

## 개선
- 클레임 상태 표시를 실제 처리 진행 상태로 바꿔, 등록한 건이 계속 "임시저장"으로 남아 보이던 문제를 해결했습니다.
- 물류 클레임을 등록해도 "제안이 등록되었습니다"로 안내되던 문구를 분류에 맞게 표시합니다.
- 제품 클레임 조회 기간 라벨을 "클레임 발생일"로 바꾸고, 라벨이 길어도 날짜가 잘리지 않도록 배치를 조정했습니다.
- 주문 처리 현황에서 아직 확정되지 않은 납품수량이 "0 BOX"로 표시되지 않습니다.
- 출근등록 완료 화면의 제품유형(상온 / 냉장·냉동) 표시가 행사에 등록된 제품유형에 맞게 나오도록 수정했습니다.
