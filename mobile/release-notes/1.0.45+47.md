# 1.0.45+47

## 새 기능
- 안 읽은 알림 개수가 앱 아이콘 배지 숫자로 표시됩니다.
- 내 일정 상세에서 참고 일정 영역이 별도로 구분되고, 사유가 항상 보이도록 개선했습니다.
- 내 일정 상세 화면을 아래로 당겨 새로고침할 수 있습니다.
- 주문서 납기일 항목에 주문 마감시간 안내가 표시됩니다.
- 주문서 제품 도구모음(선택 삭제·전체 선택·검색)이 스크롤해도 상단에 고정됩니다.
- 제품 추가 시 주문 이력 탭에서 주문별 전체 선택을 사용할 수 있습니다.

## 개선
- 진열·행사 일정이 겹칠 때 빠지던 일정을 참고 일정으로 함께 보여줍니다.
- 주문 등록 시 재고가 부족한 제품을 제품별 안내 문구로 바로 표시합니다.
- 수량을 수정한 뒤에도 확인이 필요한 항목이 그대로 유지됩니다.
- 내 주문 상세의 처리현황을 납기일 마감과 무관하게 확인할 수 있습니다.
- 주문서 화면의 여백·검색 동작을 정리해 화면 떨림을 줄였습니다.
